# Cpp_PlatformAdventure

A C++ game programming project from Chapter 15.

## Project Overview

This repository contains a platform adventure game implementation written in C++. It demonstrates game programming concepts and mechanics.

## Technology Stack

- **Language**: C++ (97.2%)
- **Build System**: CMake (2.8%)

## Getting Started

### Prerequisites

- C++ compiler (C++11 or later)
- CMake (version 3.10 or higher)

### Building the Project

```bash
mkdir build
cd build
cmake ..
make
```

### Running the Game

```bash
./Cpp_PlatformAdventure
```

## Project Structure

The project uses CMake for build configuration and is primarily written in C++.
